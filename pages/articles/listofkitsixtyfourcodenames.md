This article is a list of codenames used by [KitSixtyFour](KitSixtyFour) in their projects.

[A](#A) · [B](#B) · [C](#C) · [D](#D) · [E](#E) · [H](#H)· [K](#K) · [L](#L) · [M](#M) · [N](#N) · [O](#O) · [P](#P) · [Q](#Q) · [R](#R) · [S](#S) · [W](#W) · [Z](#Z)

<h1 id="A">A</h1>
<hr>

**Amber**
&nbsp;&nbsp;&nbsp;&nbsp;The single-gallery item component present in *[Deltari](Deltari)*. Also see [Silver](#S)

**Arctic+1**
&nbsp;&nbsp;&nbsp;&nbsp;Codename for a rewrite of [the original *Arctic*](KitSixtyFour_Arctic) with 32-bit support, as seen in *[Arctic32](Arctic32)*.

**Atheros**
&nbsp;&nbsp;&nbsp;&nbsp;Preliminary name for *KitSixtyFour Arctic*.

**Atsura**
&nbsp;&nbsp;&nbsp;&nbsp;Cancelled Minecraft server that would've been a merger of *[Horicraft](Horicraft)* and *[Horicraft (2)](Horicraft_(2))*.

<h1 id="B">B</h1>
<hr>

**Better Late Than Never**
&nbsp;&nbsp;&nbsp;&nbsp;*[StuffyXP Website](StuffyXP_Website)* Update 2.1. Referencing that the update was delayed multiple times because of Kit [not having a PC to work on the update](TheCeleryPC#death-of-the-psu).

<h1 id="C">C</h1>
<hr>

**Cairo**
The public semester release for the self-hosted edition of [Deltari](Deltari).

**[Cuber](Cuber)**
&nbsp;&nbsp;&nbsp;&nbsp;An internal successor to *[HoriWebsite](HoriWebsite)*, which features a *Watercolor*-like interface, like the visual style present in [Windows Whistler build 2419](https://betawiki.net/wiki/Windows_XP_build_2419)

<h1 id="D">D</h1>
<hr>

**DogUI**
&nbsp;&nbsp;&nbsp;&nbsp;User interface component planned for use in *Arctic* and *Arctic32*, later scrapped. It is a direct reference to [Dogui](Dogui).

**[Deltari](Deltari)**
&nbsp;&nbsp;&nbsp;&nbsp;The internal codename of the *[KuroWiki](KuroWiki)* Engine.

<h1 id="E">E</h1>
<hr>

**Everybody Features! Update**
&nbsp;&nbsp;&nbsp;&nbsp;A cancelled update to *[Stuffy's Website](Stuffy's_Website)* with the version number of `1.2`. See [Stuffy's Website [[#]] Version 1.2](Stuffy's_Website#version-12) for details.

<h1 id="H">H</h1>
<hr>

**Happy New Year!**
&nbsp;&nbsp;&nbsp;&nbsp;*StuffyXP Website* Update 2.1.1.

<h1 id="K">K</h1>
<hr>

**Kanto**
&nbsp;&nbsp;&nbsp;&nbsp;The original C++-based *Arctic* Kernel.

**Kanto32**
&nbsp;&nbsp;&nbsp;&nbsp;A rewrite of the 16-bit *[Kanto](#Kanto)* kernel featured in *Arctic32*.

<h1 id="L">L</h1>
<hr>

**LeafyOS**
&nbsp;&nbsp;&nbsp;&nbsp;Original name of *KitSixtyFour Arctic*.

<h1 id="M">M</h1>
<hr>

**Midori**
&nbsp;&nbsp;&nbsp;&nbsp;The *Arctic* bootloader.

**Midori2**
&nbsp;&nbsp;&nbsp;&nbsp;The original *Arctic32* bootloader.

**Mochi**
&nbsp;&nbsp;&nbsp;&nbsp;Bootloader in the October 2025 *Arctic32* rewrite. Named after the cat from *[Big Hero 6](https://en.wikipedia.org/wiki/Big_Hero_6_(film))*.

<h1 id="N">N</h1>
<hr>

**New Coat of Paint**
&nbsp;&nbsp;&nbsp;&nbsp;*StuffyXP Website* Update 2.0.[^1]

[**Nishi Blade**](Nishi_Blade)
&nbsp;&nbsp;&nbsp;&nbsp;Cancelled website planned to be a sucessor to *HoriWebsite*. The name is a merge of [Nishi](Nishi) (KitSixtyFour's fursona) and *Blade*, the codename of the *Web Server* edition of [Windows Server 2003](https://betawiki.net/wiki/Windows_Server_2003).

<h1 id="O">O</h1>
<hr>

**One Last Fix**
&nbsp;&nbsp;&nbsp;&nbsp;*StuffyXP Website* Update 2.1.2, a hotfix update made to address the `stuffyxp.github.io` to `horibyte.is-a.dev` migration bugs following *HoriWebsite*'s release.

<h1 id="P">P/h1>
<hr>

**Project Retriever**
&nbsp;&nbsp;&nbsp;&nbsp;*[Comet Adventure](Comet_Adventure)*.

<h1 id="Q">Q</h1>
<hr>

**Qattah**
&nbsp;&nbsp;&nbsp;&nbsp;*[Stuffy's Place](Stuffys_Place)*.

<h1 id="R">R</h1>
<hr>

**ReKanto**
&nbsp;&nbsp;&nbsp;&nbsp;The assembly-based rewrite of the *Arctic* kernel, included in [public versions of Arctic](https://github.com/kitthebifox/arctic/releases).

**Retriever**
&nbsp;&nbsp;&nbsp;&nbsp;Alternative codename of *[Comet Adventure](Comet_Adventure)*.

**[Raybolt](Raybolt)**
&nbsp;&nbsp;&nbsp;&nbsp;Cancelled successor to *HoriWebsite*, later scrapped due to [being too ambitious](Raybolt#discontinuation). A Windows 2000-like UX was planned for this project.

<h1 id="S">S</h1>
<hr>

**Silver**
&nbsp;&nbsp;&nbsp;&nbsp;Alternative codename for the single-gallery item component. Also see [Amber](#A).

**StuffyXP 2**
&nbsp;&nbsp;&nbsp;&nbsp;Preliminary versions of *[HoriWebsite](HoriWebsite)*.<br>&nbsp;&nbsp;&nbsp;&nbsp;*[AstroNT](AstroNT)*'s working title.

**SpringViewer**
&nbsp;&nbsp;&nbsp;&nbsp;Internal name of the *KuroWiki* media viewer.

<h1 id="W">W</h1>
<hr>

**Week One Update**
&nbsp;&nbsp;&nbsp;&nbsp;*Stuffy's Website* Update 1.1.

<h1 id="Z">Z</h1>
<hr>

**Zetta**
&nbsp;&nbsp;&nbsp;&nbsp;A developer version of what eventually became *[Deltari](Deltari)*.
