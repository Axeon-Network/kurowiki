***Cuber*** is the codename for a future, currently work-in-progress website intended to serve as the future personal website of [Kit](KitSixtyFour), using a design inspired from the Watercolor visual style of beta builds of Windows Whistler (XP).

A successor to *[HoriWebsite](HoriWebsite)* (and its cancelled successor tentatives *[LexSite](LexSite), *[NovaSite](NovaSite)* and *[NekoSite](NekoSite)*), work started on 9 February 2026, with the first version publicly known to exist being `0.1.1.26-02-09_kit.260209-2052`, where it refers to itself as "KitSixtyFour Code Name "Cuber" Developer Preview". As of 15 March 2026, the latest known build to exist of this project is `256.dpchk.whcuber_main(stupidbifox).260314-1758`.
*Cuber* uses the [TagGen](TagGen) component present in [Axeon Network](Axeon_Network)'s [Deltari](Deltari), the wiki engine used in [KuroWiki](KuroWiki), thus it uses the same versioning scheme as the aforementioned software. For which both use the same format as post-Windows 2000 Microsoft Windows builds.

In addition to the variant of *Cuber* used on Kit's future personal website, another variant of it, known as ***CuberSH*** (short for ***Cuber Self-Hosted***) aims to serve as a CSS framework that may be freely used by anyone.
