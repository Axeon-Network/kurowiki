***Windows Nishi & LeCat Edition 2026 Version 2003 R2 Home Premium*** (also known as ***Microsoft Windows Code Name "Longhorn" Nishi & LeCat Edition 2026 Version 2003 R2 Home Premium Service Pack 2*** in the License Agreement and ***Windows Nishi & LeCat The Third Edition 2026 Version 2003 R2 Home Premium*** in some cases) is a Microsoft Windows bootleg created by [KitSixtyFour](KitSixtyFour) in *[Making a Custom Windows Bootleg](Making_a_Custom_Windows_Bootleg)* for the [AstroNT](AstroNT) channel on March 2026. It is based on Windows Vista Home Premium Service Pack 2.

The bootleg was created in a way to mock many other Windows bootlegs (such as *[Gold Windows XP 2016](https://crustywindo.ws/Gold_Windows_XP_2016)*), thus it contains modifications such as custom branding, wallpapers and pre-installed programs (commonly called *bloatware*).

# Name
The obnoxious name is a reference to Nishi and LeCat, two cats (owned by KitSixtyFour and [Avery](AveryEclipse) respectively) originating from the *[KitsuMC](KitsuMC)* Minecraft server, while "Edition 2026" is a nod to many bootlegs that use an "Edition [YEAR]" format in their name. "Version 2003" is a reference to [Windows XP 64-Bit Edition, Version 2003](https://betawiki.net/wiki/Windows_XP_64-Bit_Edition#Version_2003) while "R2" is a reference to [Windows Server 2003 R2](https://betawiki.net/wiki/Windows_Server_2003#Release_2) and [Windows Server 2008 R2](https://betawiki.net/wiki/Windows_Server_2008_R2).
