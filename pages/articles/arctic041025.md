A screenshot of an [Arctic32](Arctic32) build compiled on 4 October 2025 running under QEMU was uploaded by [Kit](KitSixtyFour) in the Noticeboard channel on the [Nishi's Den](Nishi's_Den) Discord server. This is the only publicly known build of Arctic32 to ever be compiled.

This build is notable for being labeled under the `1.0-Sydney` version system, where *Sydney* is the code name for the code base version of the operating system, while the release name would've been *1.0*. Future releases would've followed this as the `<version><codename>` format, such as `1.1-Quadro` and `2.0-Calico`.

The screenshot also shows a version banner featuring *Mochi*, the code name of the Arctic32 bootloader, being the successor to *Midori* (as the name was changed in order to avoid confusion with [MidoriMC](MidoriMC)).

This build was also compiled under a private configuration, denoted by its "For testing purposes only." warning.

After the compilation of this build, not much was known about Arctic32 as a whole until it was cancelled in November 2025.

Due to a bug in the build system, the build tag is not displayed anywhere in the system.
