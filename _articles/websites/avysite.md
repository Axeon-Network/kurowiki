***AvySite*** (also known after its URL name, `avery.is-a.dev`) is [AvyNeko](AvyNeko)'s personal website since 23 July 2024. It launched as a complete rewrite unifying *[LynxWebsite](LynxWebsite)* and the *[Lynxmic Blog](Lynxmic_Blog)* under a single codebase using fully plain HTML+CSS.

# History
## Version 1.x
For the first month, the website had a rudimentary design using the color pallete of the initial branding of Clyron, then known under a different name (Sunn/Sunnville). This version of the website was to be retroactively known as *v1.0*; the first versions of AvySite did not have a particular version numbering scheme.

Plans were for the website layout to eventually evolve into having a Windows 2000-style look, the basic design which was rolled out in late August 2024 with *v1.1*, primarily serving as a landing page with links to socials and projects with a blog in the website as well. Already known under the name of ***ClyronWebsite*** by this point, it has been tested to work on ancient browsers as old as Internet Explorer 6.

However the layout was never considered finished. Further updates were planned to improve the overall design, but they never happened and instead only small changes have been done updating the list of projects and socials as needed.

## Version 2.x
*This section is a stub and will be finished in Release Candidate 2.*

By October 2024, plans were planted over for a complete website rewrite switching from Jekyll to Astro. It was originally planned to retain the Windows 2000-style look before it was decided by AvyNeko to scrap the design entirely in favor of a simple, more generic layout built with Tailwind CSS.

The development of v2.0 took more than 3 months, mainly due to Avery's lack of motivation and interest. An initial public beta released on 11 January 2025 with frequent rolling updates as the rewrite progressed.

v2.0 was finally finished almost a month later, on 9 February 2025, when it replaced v1.1. The final v2 release was v2.5.2 from 8 July 2025.

## Version 3.x
Plans for a version 3.0 of the website trace back to May 2025, as AvyNeko had been considering major changes that mandated a major version number bump, such as dropping Tailwind CSS and as a result regaining full control over the CSS, in order to build a Retro Frontend, mainly inspired from [KitSixtyFour](KitSixtyFour)'s *[HoriWebsite](HoriWebsite)*.
Like with the HoriWebsite retro frontend, Avery wanted to build one using Microsoft FrontPage 2003, but plans later shifted to building it on top of the existing Astro-powered website, to keep maintenence burden low.

Much of v3.0's development happened in July 2025, immediately after v2.5.2's release. The website has undergone a new major visual overhaul, nicely incorporating the design of the KayAurora branding.

v3.0 was finished and released on 18 July 2025, with the website now known as ***KayWebsite***. The Retro Frontend came later on 24 July 2025 with v3.1, [extensively and thoroughly tested](https://avery.is-a.dev/blog/2025-07-24-how-low-can-you-go-browser-compatibility/) for compatibility with ancient browsers. v3.2, released 11 August 2025, primarily focused on fixes and refinements.

v3.3 from 14 September 2025 introduced a new color scheme to go with the then-new KayAurora branding along with a bunch of fixes and improvements. The final v3 release is v3.3.1 from 7 October 2025 as AvySite switched to a new version numbering scheme starting with the next version.

## Version 25.x
AvySite officially switched from the semantic versioning system (SemVer) to a date versioning system in a year-month-revision format (vYY.MM.R) on 30 October 2025, beginning with the release of v25.10 (originally planned to be released as v3.4). Additionally, the version would be automatically determined through CI/CD on GitHub every time AvySite is built in production. The changelog page was also deprecated entirely in favor of the [AvySite version history](AvySite_version_history) KuroWiki article.

Later versions of v25.x have all mostly focused on smaller changes, bug fixes and improvements, the final release being v25.12.2 from 28 December 2025.

## Version 26.x
Per the year-month-revision versioning format introduced with v25.10, the major version number was bumped from v25 to v26 with the first AvySite version release of 2026 on 15 January of the year, known as v26.1. This was a major update to the website which brought significant fixes and changes to the website that can be seen both in the modern and retro frontends.

Throughout 2026 there would be at least one website update every month. Similarly, the next version (v26.2) was initially planned as another major update to the site, however it became a minor release, with the next major update moved to 22 March 2026 instead, coinciding with the KayAurora-AveryEclipse rebrand; this release would be numbered as v26.3. At this point the website became to be called ***AveryWebsite*** rather than ***KayWebsite***. v26.4.x and v26.5.x would then follow as minor updates.

The website has been largely overhauled again with the release of v26.6 on 29 June 2026, which involved many structural changes, tech debt cleanups, and a fresh design. v26.6.1 immediatelly followed, with v26.7 from 20 July 2026 further polishing v26.6.x while bringing a more complete, updated website design.
