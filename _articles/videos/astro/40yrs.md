***Transforming Windows 11 to Windows 1.0!? (sorta)*** is an [AstroNT](AstroNT) video made by [AvyNeko](AvyNeko). The second video of "Wave 3", it revolves around using an NT Virtual DOS Machine (NTVDM) port to x64 to run Windows 1.0 apps on Windows 11 build 29634, the latest Windows Insider build released to Experimental Future Platforms at the time of recording (28 July-2 August 2026), then replacing Windows 11's Explorer shell with the MS-DOS Executive from Windows 1.0.

It is the 1st anniversary special (the channel was created exactly a year prior, on 17 September 2025). The premiere live chat of this video was the first place an invite link to the [AstroNT Datacenter](AstroNT_Datacenter) Discord server was ever posted, towards the end of the premiere.

The codename of this video is "*40yrs*", which alludes to one of the titles purposed for this video during the planning stage "*Undoing 40 Years of Windows Evolution*", Windows 1.0 having been released in November 1985, while Windows 11 build 29634 was released in July 2026, making them over 40 years apart of each other in terms of release dates.
